# texmodel-build

The optional build side of [texmodel](https://github.com/release-art/texmodel): run `latexmk` over a `.tex` and get a typed
result, and run verifier plugins over built files. texmodel itself only renders source; you can compile that with any
LaTeX setup, and this package is one convenient way to.

See the [repository README](https://github.com/release-art/texmodel#readme).
